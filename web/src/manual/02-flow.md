## 雪花五层流程

雪花法的路线是从粗到细：先把一句话写好，再把它逐层放大成正文。Snowel 把这条路铺在左栏流程树里，你每确认一步，树就亮一步。

### 从灵感到正文的推进线

| 阶段 | 产物类型 | 说人话 |
|---|---|---|
| 灵感雪核 | premise（前提） | 一句话灵感前提，全书由此生长 |
| 一段式摘要 | synopsis（梗概） | 把一句话扩成一段话的故事 |
| 一页纸大纲 | summary（摘要）+ beat_sheet（节拍表） | 一页纸概览与全书大节拍 |
| 角色血肉 | characters（角色） | 角色档案：动机、谎言信念、弧光 |
| 场景脉络 | scene（场景卡） | 每个场景的要素清单与在场角色 |
| 正文绽放 | prose（正文） | 逐章成文，确认后写入章节文件 |

三百章的书不在大纲层一次排完：卷和章按"中雪花→小雪花"滚动展开——先对一卷生成卷主题（volume_theme）与卷三幕（volume_acts），再对每章生成章意图（chapter_intent）、微节拍组（microbeat_group，每章 3–6 个拍）与正文。展开新卷时，引擎会自动从事件日志重放出"上卷末的世界状态"（谁死了、修炼到几级、哪些伏笔没收），你不用手工做设定交接。

### 流程树：进度与待办

左栏流程树实时反映七层进度：完成层打勾，当前层高亮圆点，未动层是空心圈。流程层下挂着"卷→章"两级树，点章名即可在中间打开该章正文。判断"接下来该做什么"看两处：树上没打勾的最深一层，以及右栏提案队列里待确认的提案——确认提案就是推进流程的动作本身。

### 生成表单：七类产物

右栏的生成表单是创作主力。下拉框里是七类产物类型（与流程层一一对应）：前提、梗概、摘要、节拍表、角色、场景、正文。选好类型、点"生成提案"，产出会进入提案队列等待确认。表单还有两个可选 JSON 输入框：locate 用于定位上下文（比如指定 `{"chapter": "章 id"}`，生成正文时会自动拉取该章场景卡），extra 用于附加要求（比如 `{"notes": "文风再冷一点"}`）。

卷级与章级的展开（卷主题/卷三幕/章意图/微节拍组）在 Web 端主要由聊天侧栏代劳——对聊天说"为第三卷写主题""展开第一章"，AI 会调用对应的生成工具产提案（见《聊天侧栏》）。

### 一步一确认

每层产物的 LLM 产出都只是提案：流程树亮勾的唯一方式是你确认了对应提案。哪一层写得不满意，可以否决后重新生成，也可以下改写指令让 AI 重写（见《提案与确认》）。层级间需要修订上层设定时（比如改卷动机波及全书），走统一的修订流程，由级联检查告诉你影响面（见《封卷与 retcon》）。
