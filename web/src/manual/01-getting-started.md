## 快速上手

Snowel 是一款跑在你自己电脑上的 AI 小说创作辅助工具：它用雪花写作法（snowflake method）帮你把一句灵感一步步长成百万字级长篇，同时用知识图谱替你记住全书的设定，越写越不忘事。本手册教你把每一件功能用起来。

### 三步开始

在终端里依次执行：

```bash
pip install -e . -e ./shell   # 安装引擎核心与命令行外壳（两包结构）
snowel init                   # 在当前目录初始化项目（生成 snowel.db）
snowel web                    # 启动 Web 创作界面
```

- `snowel init` 默认作用于当前目录；想在其他目录初始化，加 `--project 路径`（或 `-p`），也可以用环境变量 `SNOWEL_PROJECT` 指定。
- `snowel web` 启动后用浏览器打开提示的地址（默认 `127.0.0.1:8642`）。
- 除了 Web，还有两个入口：`snowel mcp` 供 AI 客户端（ZCode/Claude 等）连接，CLI 的其余命令管备份、导出、封卷等本地事务——见《租约与多端》一章。

### 三栏布局一览

Web 界面是一条顶栏加三栏：

| 位置 | 名字 | 放什么 |
|---|---|---|
| 左栏 | 流程树（FlowTree） | 七层流程进度、卷→章两级树、封卷按钮 |
| 中栏 | 正文编辑页 | 章节列表、正文编辑区、拍侧栏、抽取事实 |
| 右栏 | 工作区 + 聊天侧栏 | 上半是灵感、生成表单、提案队列与提案面板；下半是常驻聊天 |

顶栏中间显示"当前卷 · 章"，右侧小圆点是会话状态：绿色为写会话，黄色为只读（原因见横幅提示，详见《租约与多端》）。第一次打开会弹出操作指引（tour），跟着走一遍大约一分钟；想重看时，点顶栏"？"打开使用手册，底部有"重看操作导览"。

### 建议的第一步：存下灵感雪核

不要急着生成，先把脑子里那句原始灵感存下来：右栏顶部是灵感面板，把原话一字不改地贴进去，点"保存灵感"。这一步不花 LLM 调用、不进提案队列，原话会永久保留——之后所有提炼物都会带着"来自哪句灵感"的血缘（见《灵感层》）。

存好之后，在下方生成表单里选"前提"，点"生成提案"。AI 产出会进入提案队列等待你确认——确认了才真正入典。接下来的推进路线，请读《雪花五层流程》。

### 动笔前的两个提醒

- AI 的产出**永远是提案**，不确认不落库；本工具尊重你对每一个字的最终裁决权。
- 生成与抽取需要接大语言模型（LLM）：默认走 litellm、模型 `gpt-4o-mini`，接入与偏好见《检索与偏好》。
