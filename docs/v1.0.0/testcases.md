# Snowel 黑盒测试用例（v1.0.0）

> 日期：2026-08-23
> 上游：requirements.md（C1–C12）、design.md（D1–D8 + E1–E5）。
> 本文只描述"给定什么输入/状态，系统应有什么可观察行为"，不指定单元/集成测试实现方式（属 plans 阶段）。
> 每条用例在"覆盖"列反向链接需求章节或裁决编号；覆盖验收见 §11 覆盖矩阵。

## 1. 约定

- **驱动方式**：用例默认通过 `snowel_core.api` 门面驱动（外壳用例除外），LLM 依赖以"可替换的生成端"表述——测试时可注入确定性生成结果，但断言只落在可观察输出（提案、事件、物化图、文件、审计表）上。
- **ID 规则**：`TC-<域>-<序号>`；域 = EV 事件溯源 / ON 本体 / PR 提案 / WB 回写 / CC 级联 / RT 检索 / FL 流程 / SH 外壳 / EX 扩展包。
- **架构铁律 1/2（领域逻辑只在 core、LLM 只在三口）与 E1 模块划分属代码结构约束**，以代码评审/依赖检查覆盖，不在黑盒用例范围；E1 的事务性语义（一次确认 = 单事务）有黑盒用例（TC-EV-08）。
