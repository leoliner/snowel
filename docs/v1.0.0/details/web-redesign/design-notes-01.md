## 1. 设计目标（发现项 → 设计动作）

| 发现项 | 设计动作 |
|---|---|
| W-6 方法论不可见 | 左栏改为**雪花进度塔**（层状态：当前/完成/待前置 + 每层待办一句话）；中栏改为**层工作台**（随当前层切换内容：L1 提案对比确认 → L2 摘要+缺口裁决 → L5 正文编辑器）；每层底部 **NEXT 行动条**（"下一步生成什么"，前置未完成时灰置并说明原因） |
| W-7 LLM 配置入口缺失 | **首开向导第一屏即配置**（接入方式/Key/模型/测试连接）；顶栏常驻**模型状态点**（绿=已配置·模型名，黄=未配置，点击改配置） |
| W-8 locate/extra 裸露 | 生成表单自然语言化：类型 chips + "附加要求"（说人话）输入框；locate 删除（由树/层选中态自动派生）；原始 JSON 收进"高级"折叠逃生口 |
| W-2 正文区无框 | 中栏层工作台化后，L5 层的正文编辑器自带框体容器；非正文层中栏展示该层产出物（不再是空白） |
| W-3 死按钮 | NEXT 行动条取代空态孤按钮，行为明确（切层/聚焦生成表单） |
| W-4 500 裸告 | 配置面补齐后，前端可依 `/api/llm/status` 提前置灰生成类操作并指引配置（修复波含壳层错误映射兜底） |

## 3. 本轮默认决策（可推翻）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 层推进为**软引导**：前置未完成不硬锁（树上灰置+提示，但生成表单仍可选任意类型） | sim 走查证明层可交叉（林晚在 L2 诞生角色）；硬锁违反"不卡死灵感" |
